# Integración Celvis

Proyecto React/Vite basado en los archivos de Figma enviados.

- Ejecutar `npm ci` y `npm run build`.
- Vercel: comando `npm run build`, directorio de salida `dist`.
- El catálogo usa config.js, catalog-api.js y promotions.js del mismo dominio.
- Acceso tienda abre admin.html existente; se eliminó el panel simulado.
- No se modificó la base de datos.
